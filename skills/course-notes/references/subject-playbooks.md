# 分学科细则

写对应学科笔记前先读相关小节；学科交叉时取并集。通用规则见 SKILL.md 与 style-guide.md，本文件只补充学科特有要求。**默认骨架（速览→知识点→易错点→公式表）与"例题/证明默认不写入"对所有学科生效**；本文件各小节定义的是该学科"知识点一节装什么"——若某类内容属于知识点本身（如计算机的代码示例、英语的词汇表），照常写入，不按"例题"处理。

## 数学类（高等数学、线性代数、概率论、复变函数、数值分析…）

- **定理四段式**：条件 → 结论 → 直观理解 → 反例/易错。条件逐条列出，缺一不可；易错点常出在"条件被忽略"上。
- **证明默认不录入**（SKILL.md 规则 8）：复习重点是"何时能用"而非"怎么推出"，但定理的条件与适用范围必须完整；用户明确要推导过程时，关键转折步（如"洛必达前先验证 0/0 型"）不可省。
- **能画的都画出来**：函数图像、积分区域、几何示意优先配图——有 Python 用 matplotlib（注意中文字体设置），否则手绘 SVG。立体解析几何图形手绘 SVG 时标注视角。
- **速查表必出**：本类笔记的速查表是复习主力，公式一个不漏。
- 符号约定与通行教材不同时（如材料用 $\subset$ 表示子集但未区分真子集），在第一次出现处统一说明。

## 工程类（电路、理论力学、材料力学、热流、化工原理、机械设计…）

- **单位与量纲全程保留**：公式后括注各量单位；方法要点中保留关键代入步骤的单位运算。
- **示意图重绘规范**：受力图、电路图、机构简图重绘为 SVG，元件符号按国标/通行画法；标注方向（力的方向、电流方向）不可省——方向错 = 图错。
- **适用条件显式化**：线性/非线性、稳态/瞬态、理想气体、小变形……工程公式的易错点几乎都在条件上，速查表"适用条件"列必填。
- **方法是主体**：题解默认不录入；把典型题的解法压成"设—列—解—验"方法要点（每步一句话）附在对应知识点，验算要领（量纲检查、极限情况检查）写进易错点而不是演算过程。

## 计算机/信息类（数据结构、算法、操作系统、计算机网络、数据库…）

- 代码示例用带语言标注的代码块，短小、可直接运行；关键行加注释，不注释每行。
- 数据结构与过程画 Mermaid：链表/树用 graph，状态机用 stateDiagram，算法流程用 flowchart，请求交互用 sequenceDiagram。
- 复杂度、协议字段、SQL 子句、锁行为等对比内容一律表格。
- 术语保留英文原文：哈希表（hash table）、进程（process）；进程/线程、并发/并行这类易混概念单独给辨析小节。
- 伪代码与真实代码二选一时，讲解用真实语言（课程用什么语言就用什么）。
- 代码示例、复杂度表、算法流程属于**知识点本身**，照常写入，不按"例题解答"省略；完整刷题推导、OJ 题解默认不写。

## 文科类（经济学、管理学、法学、文学、历史、社会学…）

- **论点—依据结构**：观点句在前，依据（法条、数据、文本、案例）紧跟其后并注明出处（章节/页码/条文号）。
- 案例默认压成"观点 + 一句依据"配对，不录入完整案例叙述；案例本身即教学目的（如法学判例的裁判规则）时保留规则部分。
- 引用材料原文：加引号标注出处，单次不超过三行；其余转述。
- 对比用表格（人物、流派、制度、学说）；时间线用 Mermaid timeline；概念之间的关系用 flowchart。
- 易混概念（如"法律权利 vs 权力""名义 vs 实际利率"）单独设辨析小节，说明区分标准。

## 英语类（大学英语、四六级备考、专业英语…）

- 词汇表固定四列：词 | 音标 | 释义 | 搭配/例句。
- 词汇表、长难句拆解、语法正反例属于**知识点本身**，照常写入，不按"例题"省略。
- 长难句三行式：原句 → 结构拆解（主谓宾、从句、插入语逐层标注）→ 翻译。
- 语法点配"正例 + 反例"各一；易错搭配（介词、搭配误用）汇入易错点小节。
- 听力/口语材料中的连读、弱读现象，用音标转写呈现。
