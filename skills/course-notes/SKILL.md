# 课程笔记（course-notes）

把大学生的课堂材料——板书拍照、课件截图、教材页、讲义文字、录音转写——整理成一份**图文结合、覆盖完整、可直接复习**的中文课程笔记：一个 Markdown 文件 + 一个同名 assets 图片文件夹。

**默认骨架**（除非用户另有要求）：`本讲速览（含关键词）→ 编号标题 + 知识点 → 易错点与考点 → 公式/结论速查表`。教材例题解答、定理证明、课后练习**默认不写入**——例题压缩成它教的方法附在对应知识点，或整体省略；图以"有用、精简"为准，默认重绘而不嵌整页原图。知识点一节的具体形态按 subject-playbooks 的学科细则执行——不同学科记的东西不同。

## 输入形态

- 图片：板书/黑板拍照、PPT 与课件截图、教材扫描页、手写笔记照片
- 文字：粘贴的讲义、教材段落、录音转写稿、自己的零散笔记
- 混合输入：图片与文字互相补充时合并处理；同一内容两处都有时取更完整的一方
- 多张图/多个文件：先判断章节与页序，按教学顺序重组，不要机械按上传顺序

## 工作流

### 1. 收集并读透输入

1. 逐张细读图片，包括板书、示意图、公式、表格、手写批注。读不清的内容记下来，供第 4 步列入"待确认"，不要猜。
2. 判断图片能否复制：用户给了本地路径、或文件就在工作目录里 → 记下路径清单，供第 4 步重绘或嵌入局部原图；图片只是粘贴在对话里、拿不到文件 → 不阻塞，按"仅重绘"模式做图文，并在交付时说明原图未嵌入。
3. 文字材料直接读。材料明显属于某门课的某章时，从内容推断课程与主题。

### 2. 澄清（至多一次）

仅当缺关键上下文才问，且一次问完，例如："这是哪门课、哪个考试范围？笔记偏应试还是偏理解？"。以下情况不问、直接做：材料自带清晰标题与编号；用户已说明课程或深度要求；材料只是单页零散草稿（按通用深度处理）。

### 3. 结构映射（覆盖清单）

动笔前，把材料中**每一项**列成清单：每个标题、定义、公式、方法与步骤、适用条件、图。这张清单是第 5 步校验的底线——笔记可以压缩表述，但清单里每一项都必须出现在笔记中。教材例题解答、证明过程、课后练习**默认不进覆盖清单**（用户明确要求保留时才列入）。

### 4. 生成笔记

先读本技能的细则文件（加载本技能时末尾给出了绝对路径清单）：用 read_file 读 references/style-guide.md（模板与写作细则，含图文编排的具体做法）；内容属于数学、工程、计算机、文科、英语某一类时，再读 references/subject-playbooks.md 对应小节。

按模板写作，执行内容规则与图文编排（下两节）。

### 5. 校验（强制，交付前逐项过一遍）

- [ ] 覆盖清单每一项都出现在笔记里；且正文没有混入例题解答/证明过程（除非用户要求）
- [ ] 公式逐条核对；与材料或通行教材不一致处按规则 4 标注
- [ ] 没有任何"见图/见原PPT/见第X页"式引用；每张图旁有图注和解读，图片不渲染时笔记仍完整可读
- [ ] assets 里每个文件都被正文引用；正文引用的每个文件都真实存在（写出失效路径是常见事故）
- [ ] 所有超出材料的补充都带（补充：）标注；全文无内部矛盾
- [ ] 无填充句；术语首次出现有中英对照；标题编号与层级一致
- [ ] 读不清的内容已列入文末"待确认"，而不是被猜出来写进正文

### 6. 输出

- Markdown 文件命名 `<课程名>-<主题>-notes.md`（如 `高等数学-特征值与对角化-notes.md`）；课程名未知就用主题名
- 图片统一放同目录的 `<课程名>-<主题>-assets/`
- 对话里给 ≤3 行摘要：这一讲讲了什么 + 笔记文件路径
- 交付后追问一句：要不要把「易错点与考点」整理成可自测的闪卡（那会用到 study-flashcard 技能）？用户同意就调 skill_use 加载它
- 用户要 Word/PDF 时，如实说明当前应用暂不支持直接导出，笔记是标准 Markdown 可自行粘贴转换；不要现造转换器

## 内容规则（硬规则）

1. **覆盖度是底线**：材料里每个标题、定义、公式、方法、条件都必须出现，可以压缩但不能漏。漏一项 = 校验不通过。例题解答与证明不在此底线之内（见规则 8）。
2. **信号密度**：每句话都在定义、解释或连接概念。不写"值得注意的是""以上就是"式填充句。
3. **自包含**：读者不需要回看原始材料。图上的信息必须转成文字、表格或重绘的图，永远不写"见原图"。
4. **忠实 + 标注**：补充材料之外的知识写成 `>（补充：…）`；材料疑似有误时保留原文并紧跟 `> ⚠ 存疑：材料写X，通行教材为Y`。不悄悄修改材料的内容。
5. **术语中英对照**：术语首次出现给英文原词，如"特征值（eigenvalue）"。用户明确要求英文笔记时全文切换为英文。
6. **不猜不编**：图片里模糊、被遮挡、看不清的内容，列入笔记末尾"待确认"清单，请用户补拍或补写，绝不编造。
7. **图文绑定**：每张图（嵌入的原图或重绘图）紧跟一行加粗图注 + 一两句解读，指出这张图在讲什么、关键看哪里。图和解读缺一不可。
8. **例题与证明默认不写入**：教材例题的解题过程、定理证明、课后练习不录入；定理只写"条件 → 结论 → 直观理解（→ 反例/易错）"。例题若教了可复用的方法且知识点未覆盖，压成一句"方法要点"附在对应小节。用户明确要求例题/证明，或 subject-playbooks 对应学科另有规定时，按那些执行。

## 图文编排

按以下优先级配图，目标是"图服务记忆与理解"——有图必有用、有图必有解读，但**图不是材料的复刻**：

1. **重绘（默认）**：结构关系、示意、数据图一律重绘成干净的小图——
   - 流程、层次、对比关系 → Mermaid（flowchart / mindmap / sequenceDiagram，标签用中文）
   - 几何图、函数草图、韦恩图、电路/受力简图 → 手写 SVG 文件存 assets（单色线条、标注字母与坐标），正文引用
   - 函数图像、数据图 → 用 matplotlib 画 PNG（run_shell 跑 python 画图脚本，命令不在白名单会请求用户批准）；先设中文字体（如 `plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei"]`）避免中文乱码；用户不批准或无 matplotlib 环境则手绘 SVG
2. **嵌入原图（受限）**：仅当原图是板书照片（潦草、无法忠实重绘）或复杂图（重绘会失真）时，把**局部原图**复制进 assets 引用；**默认不嵌教材/课件整页照片**——材料本就在用户手里，整页图信息密度低，且其中的例题、证明与正文取舍冲突。
3. **文字图表**：对比、归纳类内容用表格兜底；能用表格讲清的不做图。

需要嵌入时按语义重命名为 `NN-描述.png`（`NN` 为正文出现顺序的两位编号），相对路径引用。只做嵌入与重绘，不做裁剪、去杂物等修图（除非环境里恰好有 ImageMagick）。
